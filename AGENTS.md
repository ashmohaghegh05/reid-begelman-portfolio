# AGENTS.md

## Project

Reid Begelman Professional Portfolio

## Client

Reid Begelman

## Instructions

- Read `PROPOSAL.md` and `PRD.md` before making major changes.
- Use plain HTML and CSS.
- Keep the three main pages:
  - `index.html`
  - `resume.html`
  - `contact.html`
- Keep shared styles in `style.css`.
- Use semantic HTML.
- Use relative paths for local files.
- Keep the same navigation on every page.
- Preserve real client content.
- Do not use placeholder text.
- Keep the site responsive.
- Do not add frameworks unless specifically requested.
- Keep the code readable and easy to explain.
- Test links after changes.
- Test both desktop and mobile layouts.

## Design Direction

The site should feel professional, modern, editorial, and appropriate for recruiters.

Use the existing navy, cream, and orange color system consistently.

Avoid generic AI portfolio styling.

## AI Use

AI may help generate, explain, debug, and improve code, but every change should be reviewed before it is accepted.
